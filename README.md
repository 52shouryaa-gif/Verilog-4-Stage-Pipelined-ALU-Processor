# Verilog-4-Stage-Pipelined-ALU-Processor
4-stage pipelined processor datapath implemented in Verilog HDL. The design includes a register bank, arithmetic logic unit (ALU), and memory write-back stage. Supports multiple arithmetic and logical operations such as add, subtract, multiply, shift, and bitwise operations. Includes a complete testbench for functional verification and simulation.
# Verilog 4-Stage Pipelined Processor

## Features
- 16-bit datapath
- 4-stage pipeline
- Register bank (16 registers)
- Memory (256 locations)
- ALU operations: ADD, SUB, MUL, AND, OR, XOR, SHIFT, NOT
- Testbench included

## Tools Used
- Verilog HDL
- ModelSim / Vivado / Icarus Verilog

## Files
- pipe2.v      → Main design
- tb_pipe2.v   → Testbench
